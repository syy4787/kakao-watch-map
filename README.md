# 갤럭시워치 전용앱 — 카카오맵 길찾기 + 유튜브 음악 (Wear OS)

갤럭시 워치9 44mm(1.47″ 480×480 원형)에 맞춘 **걷기·대중교통·자전거 길찾기 전용** 지도 앱입니다.
자동차 길찾기는 넣지 않았습니다. 카카오맵 앱의 길찾기 흐름(도착지 검색 → 이동수단 탭 → 경로 목록 → 상세 → 지도에서 안내)을 워치 화면에 맞게 옮겼습니다.
아이콘·로고·화면 디자인은 카카오 것을 베끼지 않고 Material 아이콘으로 새로 만들었습니다.

## 기능

| 화면 | 하는 일 |
|---|---|
| **첫 화면** | 워치 앱 목록의 아이콘은 **갤럭시워치 전용앱** 하나. 누르면 큰 동그라미 두 개 — **카카오맵**(길찾기·버스) / **유튜브**(노래·내 믹스) — 중에 고른다. 고른 앱에서 뒤로 가면 워치 화면으로 — 지도는 닫히지 않고 뒤로 가 있다가, 첫 화면에서 다시 고르면 **보던 그대로**(안내 중이던 지도·타일로 연 검색 화면 등, 새로 띄우지 않아 바로 뜸). 아래 '앱 정보 · 업데이트'(새 버전이 있으면 '새 버전 · 탭해서 업데이트', 뒤로 가면 고르는 화면) |
| **지도** | 원 전체를 지도가 채움. 카카오 로고는 원 안 위쪽으로 옮김(가리면 안 됨). 원 테두리를 따라 길찾기·확대·내 위치·축소 버튼이 놓이고, **내 위치 버튼은 카카오맵처럼 늘 보임**(지도를 끌어 옮겼다가 바로 내 위치로) — 나머지는 4초 뒤 숨고 지도를 톡 치면 다시 나타남. 경로를 띄운 동안엔 버튼이 안내를 가리지 않게 3시 ✕(안내 종료)·9시 내 위치만 |
| 베젤·크라운 | 시계 방향 = 확대, 반대 = 축소 |
| 내 위치 버튼 | 한 번 = 따라가기, 두 번 = 나침반(지도가 내가 보는 방향으로 회전), 세 번 = 끄기. 지도를 손으로 끌면 따라가기가 풀리고, 안내 중이면 손을 뗀 뒤 8초(또는 손목을 다시 올리면 바로) 다시 따라감 |
| **도착지 검색** | 음성·키보드·손글씨로 검색(카카오 장소 검색), 최근 목적지 10개 |
| **집·회사** | 카카오맵처럼 검색 첫 화면에 집·회사 바로가기. 등록 안 됐으면 톡 → 검색해서 등록, 등록됐으면 톡 한 번에 길찾기(배너에 '→ 집'). 최근 목적지·검색 결과를 **길게 누르면** 집·회사로 등록, 등록된 집·회사를 길게 누르면 바꾸기·지우기 |
| **타일** | 워치 화면을 옆으로 넘기면 나오는 카드 '길찾기 바로가기': 집 · 회사 · 검색 버튼. 추가: 타일 화면을 길게 누름 → ＋ → 길찾기 바로가기. 집·회사를 바꿀 때만 다시 그려서 배터리를 쓰지 않음 |
| **길찾기** | 위쪽 탭: 대중교통 · 도보 · 자전거 (마지막에 고른 탭 기억). 카카오맵처럼 탭 아이콘 아래에 **걸리는 시간**, 세 수단 중 **가장 빨리 도착하는 수단은 초록**. 보고 있는 탭을 먼저 찾고 나머지 탭은 뒤이어 받음(직선 거리로 도보 15km·자전거 50km 가 넘으면 그 탭을 열 때만) |
| 대중교통 | 경로 카드마다 소요 시간·도착 예정 시각·요금·환승 횟수·도보 시간·구간 막대(노선 색). 첫 탈 것이 버스면 그 버스의 **실시간 도착**(공공데이터 키가 있을 때, 카카오맵 표기 `311번 3분 (2번째 전) · 다음 14분`, 아무 버스나 타도 되는 구간은 `105 곧 도착 · 115 7분`) — 목록을 보는 동안 45초마다 새로, 같은 정류장은 한 번만 물음. 여러 노선 중 아무거나 타도 되는 구간은 카카오맵처럼 `105외 5대`, 거리 따라 달라지는 요금은 `1,500~2,800원`. 가장 빨리 도착하는 경로에 **가장 빠름** 표시, 처음엔 **최소시간** 순(가장 빠른 경로가 맨 위). 위쪽 칩 두 개를 톡 하면 카카오맵처럼 **전체·버스·지하철·버스+지하철**로 거르고(있는 종류만, 개수 표시) **최소시간·최소환승·최소도보·추천순**(카카오가 준 순서 그대로)으로 정렬(정렬은 기억) |
| **기차·고속·시외버스** | 먼 곳(직선 25km 넘게)이면 카카오맵처럼 **열차(KTX·SRT·ITX·무궁화)·고속버스·시외버스** 경로도 함께 (카카오 대중교통 API는 대전→서울도 시외·직행버스 갈아타기 3시간짜리만 줌). 출발지·도착지 근처 역(가장 가까운 역 + 가장 가까운 KTX 역 + 근처 큰 역)과 터미널을 카카오 장소 검색으로 찾고, 공공데이터(TAGO) 오늘 시간표를 받아, 역까지·역에서 목적지까지는 카카오 대중교통(700m 안은 도보)으로 이어 한 경로로. 카드엔 `KTX 105 09:58 출발 · 대전역`, 거르기 칩에 **열차·고속버스·시외버스**. 시내 경로를 먼저 보여 주고 시간표 경로는 오는 대로 뒤에 붙임(최대 20초). 시간표 경로는 도착 시각이 정해져 있어 볼 때마다 남은 시간이 줄고, 나가야 할 시각이 지난 편은 빠짐(그 종류가 다 지나가면 다음 편을 다시 찾음, 5분에 한 번까지). TAGO 오늘 자료에 KTX 가 통째로 빠진 날(2026-10-13 대전→서울 실제로 28편 중 KTX 2편)은 다음 주 같은 요일 시간표로 채우고 목록·상세에 그렇다고 적음. 역·터미널 목록은 워치에 30일 저장 |
| 경로 상세 | 출발 → 도보 → 버스(승차 정류장, 정거장 수, 하차 정류장, 탈 수 있는 버스 번호 전부, 실시간 도착 30초마다 갱신) → 지하철 → … → 도착. 기차·고속버스는 `[KTX-산천 105] 09:58 출발 / 대전역 승차 · 53분 / 서울역 10:51 도착` (실시간 버스는 기차를 타러 가는 버스만) |
| 도보·자전거 | 카카오맵과 같은 **경로 옵션 3가지**를 한꺼번에 찾아 카드로: 자전거 **자전거도로 우선**(조금 돌아가도 자전거도로로) · **최단 거리** · **편안한 길**(심한 경사·계단을 피한 넓은 길), 도보 **큰길 우선** · **최단 거리** · **편안한 길**. 카드마다 시간·거리·도착 시각, 가장 빨리 도착하는 카드에 **가장 빠름**, 같은 길이 나온 옵션은 한 카드로 합침. 처음엔 가장 빠른 길이 골라져 있고, 다른 카드를 누르면 그 옵션을 다음 길찾기에서도 먼저 고름('가장 빠름' 카드를 누르면 다시 늘 가장 빠른 길). 고른 길의 갈림길 안내 목록, **안내 시작** / **지도에서 보기**. 경로를 벗어나 재탐색할 때도 고른 옵션 그대로 |
| **안내 배너** | 카카오맵 길안내처럼 왼쪽에 회전 화살표(또는 버스·지하철 아이콘)와 그 아래 거리, 오른쪽에 짧은 할 일과 장소 하나: `[↰ 35m] 좌회전 / 역전약국 앞`, `[🚌 171m] 617번 승차 / 시청역`, `[🚌 1.2km] 617번 타는 중 / 은하수네거리 하차`. 글자 폭만큼만 차지하고 살짝 투명. 긴 이름은 글자를 조금 줄여 잘리지 않게. 톡 하면 둘째 줄 접기. 아래엔 한 줄 알약 `8.3km · 14:52 도착` (톡 → 경로 상세) |
| **정류장 수** | 버스·지하철을 타는 동안 카카오맵 알림("정류장 3개(7분)")처럼 `[🚇 3.4km] 3정거장 · 7분 / 정부청사 하차` (남은 시간 = 구간 소요 시간 × 남은 거리 비율, 정류장 위치를 모르면 `7분 후 하차`), 다음 정류장이 내릴 곳이면 "다음 정류장 하차" + 하차 진동 (카카오맵처럼). 지하철역 위치는 카카오 장소 검색으로 바로 찾고, 버스 정류장 위치는 공공데이터 키가 있을 때 노선 정류소 목록으로 찾음. 못 찾으면 남은 거리(버스 500m·지하철 1km)로 알림 |
| **안내 진동** | 화면이 꺼져도 계속 따라가며 손목만으로 구별되게: **좌회전 35m 전 짧게 2번 · 우회전 짧게 3번 · 유턴 4번 · 횡단보도·계단 길게 1번** (자전거는 70m 전, 그냥 직진으로 이어지는 구간은 진동 없음), 정류장·역 30m 앞 승차 알림(중간 2번), 내릴 곳 가까이 하차 알림(길게 3번), 내릴 정류장을 지나치면 아주 길게 2번 + 대중교통 경로 자동 재탐색, 경로 이탈 빠르게 5번(갈림길을 지나쳐 직진하면 30m 쯤에서), 도착 길게 1번. 진동은 '알람' 용도로 울려서 워치의 터치 진동을 꺼 두었거나 절전 모드·방해 금지 중에도 빠지지 않음. 안내는 지도가 다 뜨기 전에 바로 시작(지도 인증이 늦거나 실패해도 진동 안내·진행 중 아이콘은 됨) |
| **안내 판단** | GPS 가 튀어도 구간을 건너뛰지 않게(걷는 속도로 못 갈 거리는 두 번 확인), 정류장에서 기다리는 동안 흔들려도 '탔다'고 보지 않게(노선을 따라 60m 넘게 두 번), 지하철(지하)은 기지국 위치로 하차 알림. 도보·자전거는 경로를 벗어나면 **자동 재탐색**(여정당 10번까지, 실패하면 간격을 두고 재시도). 도착 후 5분 또는 300m 넘게 떠나면 안내가 스스로 끝남. 워치페이스의 '진행 중' 아이콘을 누르면 지도로 돌아옴. 길안내는 '정확한 위치' 권한이 필요(대략적 위치만 있으면 다시 요청) |
| **기차·고속버스 타는 길안내** | 역에서 기다리면 `[🚆] KTX 105 승차 / 09:58 출발` (알림엔 '12분 후'). 역에서 직선으로 1.5km(버스 0.8km) 넘게 가야 '탔다'(출발 2분 전부터만, 큰 역 안을 걸어 다니는 것과 구별), 타는 중엔 `48분 후 하차 / 서울역 10:51`(시간표 도착 기준). 선로는 모르고 역과 역을 직선으로 이었으므로 선로가 수 km 벗어나 굽어도 이탈로 보지 않고 걸어온 길로 되돌아가지 않음, 기차 안의 기지국 위치(1~2km)도 씀. **내릴 역 4km(고속·시외버스 2km) 앞에서 하차 진동**. 역을 지나치면(가장 가까웠던 때보다 기차 4km·버스 2km 넘게 멀어짐) 진동 + 다음 역에 서면 그 자리에서 다시 찾기. 타려던 편이 떠났는데 안 탔으면 '떠남' 진동 + **다음 편으로 다시 찾기** — 역에 있으면 늦게 떠날 수도 있어 기차 10분·버스 15분, 아직 역으로 가는 중이면 3분 뒤. 역으로 가다 길을 벗어나면 그 역까지만 다시 찾고 기차는 그대로(시간 안에 닿으면) |
| **버스 타기** | 정류장으로 걸어가거나 기다리는 동안 배너에 **실시간 도착**(`311번 3분 (2번째 전)`, 45초마다 — 그때만 물어 배터리 아낌), 정류장에 있거나 150m 안에서 **2분 안으로 오면 진동**(한 번). 기다리는 동안은 5초 GPS 로 버스에 탄 걸 바로 알아챔. 실시간 도착은 **가는 방향의 정류장**으로 찾음(길 건너 같은 이름 정류장과 노선 순서로 구별, 대전 급행은 `급행2`, 같은 번호의 다른 노선은 TAGO 노선 번호로 구별, 이름을 '/'로 붙인 정류장도). 타는 중 판단은 8초 넘게 이어진 속도로(신호 대기·GPS 튐에 흔들리지 않게), 버스를 타고 빠르게 가는 동안은 도착으로 보지 않음, 정류장을 걸어서 지나쳐도 '탔다'로 보지 않음. 같은 정류장에서 갈아타면 내리자마자 `514번 환승` |
| 정류장까지 걷는 길 | 카카오 대중교통 응답에는 집→첫 정류장, 마지막 정류장→도착지 도보가 단계로 빠져 있어서(실제 응답으로 확인) 카카오맵처럼 '도보 N분'으로 채워 넣고 안내함. 경로 상세를 열면 그 두 구간을 **카카오 도보 길찾기의 실제 걷는 길**로 받아(동시에, 3초까지) 걷는 시간·거리를 고치고(기차·고속버스 경로는 그만큼 '늦어도 이때 출발'·도착 시각도 옮김, 시내 경로의 전체 소요 시간은 카카오맵과 같은 숫자 그대로), 지도에는 카카오맵처럼 **점을 찍은 회색 선**으로 길 따라 그림(환승 도보는 카카오가 준 길 그대로). 안내 시작을 누를 때 아직 받는 중이면 다 받을 때까지만(길어야 3.5초) 기다리고, 안내 중 다시 찾은 경로도 같은 방식(3초). 정류장까지는 아는 길로 가도 되게 이 구간에선 '경로 이탈'을 판단하지 않음 |
| 저전력 화면 | 손목을 내리면 지도 엔진 대신 **선만 그린 미니 지도**(경로·내 위치·목적지 방향·다음 안내)를 검은 바탕에 표시. 길찾기·경로 상세·유튜브 음악 화면은 Wear OS 6+ 에서 손목을 내려도 켜진 채 남으므로 검은 화면에 목적지 요약만 두고 실시간 버스 새로 고침도 쉼 |

## 갤럭시 워치9 44mm가 이 앱을 감당하나요?

실제 워치(SM-L350, Wear OS 7 / Android 17)에 설치해서 지도·인증·내 위치 표시까지 확인했습니다.

| 항목 | 워치9 44mm | 이 앱에 필요한 것 | 판단 |
|---|---|---|---|
| 칩 | Snapdragon 5코어 3nm, GPU Adreno | 480×480 벡터 지도 그리기 | 여유 있음 (지도 SDK 가 'High spec' 으로 인식) |
| 메모리 | RAM 2GB | 지도 엔진 포함 수백 MB | 충분. 앱 정보 화면에서 실제 사용량 확인 가능 |
| 앱 실행 환경 | **32비트(armeabi-v7a)** — 실제 워치에서 확인 | 32비트용 지도 엔진 포함 | 업데이트 때는 32비트 전용 APK 만 받음 (처음 설치용 APK 엔 32·64비트 둘 다) |
| 위치 | 2주파 GPS(L1+L5), 지자기 나침반 | 도보 안내 정확도, 방향 표시 | 도심에서도 유리 |
| 배터리 | 445mAh | 화면과 GPS 가 가장 많이 씀 | **가장 큰 제약** → 아래 우회법 |

### 배터리 우회법 (기능은 그대로 두고 덜 쓰기)

- **필요한 순간에만 촘촘하게 위치 받기**: 화면을 볼 땐 1초. 손목을 내린 동안은 '다음에 할 일'(회전·횡단보도·승하차)까지 거리 기준으로 60m 안·이탈·출발 직후 1초, 250m 안 2초, 긴 직진 4초(8초까지 모아 받기), 신호·정류장에서 멈춰 있으면 갈림길 바로 앞이어도 5초, 버스에서 내릴 곳이 3km 넘게 15초 · 1.5km 넘게 10초(모아 받기), **지하철(지하)은 GPS 대신 기지국·Wi-Fi 위치 10초**, 실내 출발로 1분 넘게 경로에 못 오르면 3초. 다른 앱이 GPS 를 1초마다 받아도 우리 앱은 계획한 간격보다 자주 깨지 않음. 화면을 다시 켜면 모아 둔 위치를 바로 받아 따라잡음.
- **기차·고속버스**: 역(터미널)에서 기다리는 동안 출발 3분 전까지 Wi-Fi·기지국 위치 30초. 타는 중엔 내릴 역이 10km 넘게·도착 10분 넘게 남았으면 **GPS 를 끄고 기지국·Wi-Fi 위치 1분**(KTX 안은 GPS 도 잘 안 잡힘, 중간 역 정차 중에도 그대로) → 4km·3분 전까지 GPS 10초 → 그 안 3초. 시간표보다 늦어지면 거리로만 판단. 역을 지나쳐 다음 역까지 가는 동안도 저전력.
- **배터리 15% 이하(충전 중 아님)**: 위치 간격을 두 배로(회전 앞도 2초) — 안내는 그대로.
- **폰 GPS 활용**: 워치가 폰과 연결돼 있으면 Wear OS 가 폰·워치 중 전력이 덜 드는 쪽 위치를 씀(시스템 기본 동작이라 따로 할 일 없음).
- **손목 내림 = 선만 그린 미니 지도**: 지도 엔진(GPU)·네트워크 없이 경로 좌표로 직접 그림. 화면의 85% 이상이 검정, 윤곽선만 사용(번인 방지 이동은 시스템이 함). 5초에 한 번, 또는 안내 단계가 바뀔 때만 다시 그림. 가려진 지도 배너는 그동안 고치지 않음.
- **도착 뒤**: 2분간 저전력 위치(Wi-Fi 위주), 그 뒤엔 다른 앱이 받은 위치만 얻어 쓰기(추가 전력 0), 5분 뒤엔 안내가 스스로 끝나 진행 중 아이콘·위치가 모두 꺼짐.
- **GPS 신호를 10초 넘게 못 받으면**(지하·실내) 배너에 'GPS 신호 약함'을 띄워 화면만 보고 기다리지 않게.
- **경로 밖에서 멈춰 있으면**(안내를 켠 채 카페·집에 들어감 등) 1초 GPS 대신 5초, 10분 넘으면 GPS 를 끄고 Wi-Fi·기지국 위치 15초 + 4분쯤마다 GPS 로 한 번(최대 30초) 확인해서 걷기 시작하면 바로 GPS 안내로. Wi-Fi·기지국 위치가 수십 m 튀는 것은 '걷기'로 보지 않음(멈춘 곳에서 오차보다 확실히 멀어져야 움직임). **경로를 벗어난 채 30분**이면 알림을 남기고 안내를 스스로 끝냄 — 출발 전 실내에서 기다리는 것, 버스·지하철 타는 중은 끝내지 않음.
- **업데이트**: 새 버전 확인은 6시간마다·앱을 열 때 5분에 한 번, 어떤 연결에서든(1KB 도 안 됨). 내려받기·설치도 어디서나 — 밖에서는 폰 데이터를 씀(사용자가 그러기로 함). 폰 블루투스로 받다 끊기면 받은 데부터 이어받고(한 번에 3번까지 다시 잇기), '지금 업데이트'로 받는 동안엔 화면을 켜 둠(꺼지면 느린 블루투스 내려받기가 멈출 수 있음). 받은 파일이 update.json 과 계속 다르면(손상) 같은 릴리스는 자동으로 두 번까지만 받음(폰 데이터 낭비 방지 — '지금 업데이트'는 언제든). 자동 업데이트·설치가 실패한 까닭은 '최근 오류 기록'에 남음. 안내 중에는 설치를 미룸(설치하면 앱이 다시 시작되므로). 워치 CPU(32비트) 전용 APK 만, 코드까지 압축해서 받으므로 한 번에 약 13MB. 설치하고 남은 APK 는 다음 확인 때 지움.

폰에서 지도를 그려 이미지로 보내는 방식도 검토했지만, 카카오 지도 SDK 는 폰 화면이 켜져 있어야 그릴 수 있고, 블루투스로 이미지를 계속 받는 데 워치 배터리가 더 들어서 쓰지 않았습니다.

### 2) 워치에 설치 — ✅ 완료 (컴퓨터에서 무선 디버깅으로)

다시 설치해야 할 때(새 워치 등):
1. 워치 **설정 > 워치 정보 > 소프트웨어 정보 > 소프트웨어 버전** 5~7번 톡 → 개발자 옵션

3. `adb install -r -g kakao-watch-map.apk` (‑g: 위치·알림 권한 미리 허용)
4. `adb shell appops set com.mywatch.kakaomap REQUEST_INSTALL_PACKAGES allow` (앱이 스스로 업데이트하게)

3. 그 뒤로는 main 에 올라갈 때마다 자동으로 새 버전(v103, v104 …)이 게시됩니다.
4. 워치 앱에는 저장소 `syy4787/kakao-watch-map` 이 이미 들어 있습니다. 다른 계정을 쓰려면 **길찾기 > 앱 정보·업데이트 > GitHub 아이디 바꾸기**.

워치는 6시간마다(앱을 열 때는 5분마다) 새 버전을 확인하고, **집 Wi-Fi 든 밖에서 폰 블루투스·LTE 든** 앱을 안 쓰는 동안 알아서 설치합니다(밖에서는 폰 데이터로 한 번에 약 13MB). 길안내 중에는 끝날 때까지 미룹니다.
바로 받으려면 앱을 열고 첫 화면 아래 **업데이트**(새 버전이 있으면 파란 **새 버전 업데이트**) 한 번 — 확인하고 바로 받아 설치하며, 받는 동안 화면이 켜져 있습니다.
설치 전에 ① SHA-256 ② 패키지명 ③ 버전이 더 높은지 ④ 지금 앱과 같은 서명 키인지 확인하고, 하나라도 틀리면 설치하지 않습니다.
앱이 스스로를 업데이트하므로(설치 주체 = 앱 자신) 워치에서 확인 버튼을 누를 필요가 없습니다.

### 4) (선택) 실시간 버스 도착·버스 정류장 수 켜기

1. [공공데이터포털](https://www.data.go.kr) 가입·로그인
2. 아래 세 가지를 검색해서 각각 **활용신청** (개발계정은 보통 바로 승인). 이름에 **(TAGO)** 가 들어간 것 — 비슷한 이름의 '국토교통부_버스정류장', '버스노선별 경유정류장'(교통카드 통계용, 좌표 없음)은 필요 없음
   - **국토교통부_(TAGO)_버스도착정보** — "3분 (2번째 전)" 실시간 도착
   - **국토교통부_(TAGO)_버스정류소정보** — 정류장 찾기
   - **국토교통부_(TAGO)_버스노선정보** — 버스 타는 중 "3정거장 · 7분"의 정류장 위치
   - **국토교통부_(TAGO)_열차정보** · **국토교통부_(TAGO)_고속버스정보** · **국토교통부_(TAGO)_시외버스정보** — 먼 곳 길찾기의 기차·고속·시외버스 시간표 (같은 키로 됨 — ✅ 2026-10-13 신청·승인 완료)
3. **마이페이지 > 데이터 활용 > Open API > 활용신청 현황**에서 **일반 인증키**를 복사 (인코딩·디코딩 아무거나 — 앱이 둘 다 받음)
4. GitHub 저장소 **Settings > Secrets and variables > Actions > New repository secret** — 이름 `TAGO_SERVICE_KEY`, 값에 붙여넣기
5. 다음 빌드부터 들어감 (Actions 에서 **Build & release > Run workflow** 를 누르거나 Claude 에게 말하면 바로 새로 빌드). 승인 직후 1~2시간은 키가 아직 안 먹을 수 있음

### 5) (선택) 유튜브 음악을 유튜브 자체 검색으로 — 유튜브의 모든 영상에서 찾기

키가 없어도 카카오 동영상 검색으로 유튜브 영상을 찾지만, 유튜브에만 있는 커버·라이브까지 다 찾으려면 무료 YouTube Data API 키를 넣으세요(5분, 하루 검색 약 100번 무료).

1. [Google Cloud 콘솔](https://console.cloud.google.com) 로그인 → 처음이면 약관 동의
2. 위쪽 프로젝트 선택 → **새 프로젝트** → 이름 아무거나(예: `watch-tube`) → 만들기
3. **API 및 서비스 > 라이브러리** → `YouTube Data API v3` 검색 → **사용**
4. **API 및 서비스 > 사용자 인증 정보** → **+ 사용자 인증 정보 만들기 > API 키** → 키 복사
5. (권장) 만든 키 **수정** → **API 제한사항: 키 제한 → YouTube Data API v3** 만 체크 → 저장. 이게 핵심 — 공개 APK 에서 누가 키를 꺼내 써도 유튜브 검색 한도만 줄고(돈이 나가지 않음), 한도를 다 쓰면 앱은 그날 카카오 검색으로 넘어감.
   덤으로 **애플리케이션 제한사항: Android 앱** → 패키지 `com.mywatch.kakaomap`, SHA-1 `2D:B3:DE:4F:C3:E9:9A:A5:67:E3:78:7E:EC:A1:81:A4:AA:C6:09:CA` 도 넣을 수 있음 (앱이 이 두 값을 요청에 붙여 보냄 — 다만 둘 다 공개된 값이라 흉내 낼 수는 있음)
6. GitHub 저장소 **Settings > Secrets and variables > Actions > New repository secret** — 이름 `YOUTUBE_API_KEY`, 값에 붙여넣기
7. Claude 에게 말하거나 Actions 에서 **Build & release > Run workflow** → 다음 업데이트부터 유튜브 자체 검색 (검색 결과 위에 '유튜브 검색 · N개'로 표시). 배포할 때마다 키가 되는지 확인해 실행 요약에 **유튜브 키 확인** 알림(되면)이나 경고(안 되면, 까닭과 함께)가 뜸

### 6) 워치에서 유튜브 듣기 — 재생 화면 올리기 (GitHub Pages)

`web/tube/index.html` 이 `main` 에 올라가면 Actions 의 **Watch player page** 가 `gh-pages` 브랜치로 올리고, GitHub Pages 가 `https://<사용자>.github.io/<저장소>/tube/` 로 보여 줍니다. GitHub Pages 가 꺼져 있으면 한 번만: 저장소 **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `gh-pages` / (root) → Save**. 재생 화면에 닿지 못하면 앱은 알아서 폰 유튜브로 틉니다. 워치에는 Play 스토어에서 **삼성 인터넷**을 설치해 두세요.

## 알아 둘 한계 (솔직하게)

- **기차·고속·시외버스는 시간표입니다**(공공데이터 TAGO). 지연·운휴·매진은 반영되지 않고, 열차 위치·지연 실시간 정보는 공개 API가 없습니다. 시간표에 KTX 가 빠진 날은 다음 주 같은 요일 시간표로 채우므로 그날만 다른 열차는 틀릴 수 있습니다(목록에 표시).
- 역·터미널은 카카오 장소 이름과 TAGO 이름을 맞춰 찾으므로(서관·동관, '부산서부'↔'부산사상' 같은 이름 차이는 처리) 작은 정류소나 이름이 많이 다른 터미널은 빠질 수 있습니다. 같은 이름에 TAGO 번호가 여럿인 터미널은 첫 번호만 봅니다.
- 선로·고속도로 모양을 몰라 **지도에는 역과 역을 직선으로** 그립니다.
- 실시간 버스 도착은 TAGO 가 지원하는 지역만 나옵니다. 서울·경기는 별도 시스템이라 정보가 비거나 일부만 나올 수 있습니다.
- 지하에서는 GPS가 안 잡혀서 **지하철 하차 진동은 지상 구간에서만** 동작합니다. 버스는 내릴 정류장 약 500m(짧은 구간은 절반) 전에 알립니다.
- 카카오 REST 키는 APK 안에 들어 있어서, 공개 저장소의 APK를 분석하면 꺼낼 수 있습니다. 결제(월렛)를 연결하지 않았다면 돈이 나가지는 않고 최악의 경우 하루 무료 한도가 소진됩니다. 이상하면 키를 새로 발급해 GitHub Secret `KAKAO_REST_API_KEY` 로 넣으면 다음 빌드부터 바뀝니다.
- **워치용 공식 유튜브 앱이 없어서**, 워치에서 들을 땐 삼성 인터넷 속 **유튜브 공식 플레이어(임베드)**로 틉니다. 다른 앱이 유튜브 영상·소리를 직접 받아 재생하는 건 유튜브 약관 위반이라 이 앱은 검색·고르기만 합니다. 그래서: 워치 화면이 꺼지면 소리도 멈추고(유튜브 규칙 — 보이지 않는 플레이어로 틀지 않기. 재생하는 동안 화면을 켜 두므로 배터리를 꽤 씀, 잠자기 타이머로 줄일 수 있음), 올린 사람이 다른 곳 재생을 막아 둔 곡은 건너뛰며, 처음 한 번은 플레이어 가운데 ▶를 눌러야 할 수 있습니다(브라우저의 소리 자동 재생 막기). 재생은 플레이어가 보일 때만 시작하므로 아래 화면에서 ▶·⏭ 를 누르면 화면이 먼저 플레이어로 올라갑니다. 소리는 워치 스피커나 워치에 연결한 이어폰으로. 화면이 꺼져도 계속 들으려면 길게 눌러 **폰 유튜브에서**(프리미엄 백그라운드 재생).
- 유튜브 API 로는 내 계정의 홈 추천 목록을 받을 수 없어서(공식적으로 막힘) 워치 화면에 '추천 목록'을 띄우지는 못합니다. 대신 고른 곡을 **믹스**로 틀어 유튜브가 비슷한 곡을 계속 이어 줍니다(재생 화면 아래 '다음 곡').
- 카카오 동영상 검색(키가 없을 때)은 유튜브 영상 일부만 찾습니다. 없으면 '폰 유튜브에서 이 검색 열기'나 유튜브 API 키(설정 5번)를 쓰세요.
- 워치마다 나침반 방향이 반대로 돌면 `AppConfig.HEADING_SIGN` 을 `-1` 로 바꾸면 됩니다(말씀만 하시면 고쳐 드립니다).
- 카카오맵 SDK 는 ARM 전용이라 PC의 x86 에뮬레이터에서는 지도가 안 뜹니다. 실제 워치로 테스트하세요.

## 개발자용

- Android Studio **Panda 2 (2025.3.2) 이상**, Android Gradle Plugin 9.1.1(Kotlin 내장), Gradle 9.3.1, JDK 17+
- compileSdk/targetSdk 36, minSdk 30(Wear OS 3+), 패키지 `com.mywatch.kakaomap`
- 키는 소스에 넣지 않습니다. 로컬 빌드는 `local.properties` 에:
  ```
  kakao.rest.key=REST_API_키
  tago.service.key=공공데이터_키(선택)
  update.repo=아이디/kakao-watch-map   (선택)
  release.storeFile=/경로/release.jks  (선택, 릴리스 서명)
  release.password=비밀번호            (선택)
  ```
