# 워치용 유튜브 앱 — 설계

날짜: 2026-10-14 · 대상: 갤럭시워치9 44mm (Wear OS 6, 480×480 원형, 32비트 armeabi-v7a)

## 목표

워치에서 **진짜 유튜브 앱처럼** 쓰는 앱. 앱 안에서 둘러보고(홈·검색·구독·보관함·채널·재생목록),
앱 안에서 재생하고(유튜브 공식 플레이어), 구글 계정으로 로그인해 내 구독·재생목록·좋아요를 본다.

사용자가 고른 것 (2026-10-14):
- 재생: **앱 안에서 바로** — 앱에 브라우저 엔진(GeckoView)을 넣는다. 안 되면 삼성 인터넷 재생 화면으로 자동 전환.
- 로그인: **같이 설정** — 구글 클라우드 OAuth 클라이언트(TV·입력 제한 기기)를 사용자와 함께 만든다.

## 안 되는 것 (규칙)

- **화면이 꺼져도 재생 / 프리미엄 재생**: YouTube API 개발자 정책 III.I.9 는 보이지 않는 플레이어(background player)의
  재생을 금지하고, 공식 플레이어(임베드)는 로그인되지 않는다. 유튜브·유튜브 뮤직 앱만 가능.
- 홈 '추천'(개인 맞춤), 시청 기록, 나중에 볼 동영상: API 로 받을 수 없음 → 인기 차트·구독 새 영상·이 앱의 최근 기록으로 대신.
- 영상·소리를 직접 받거나 저장하기, 광고 막기, 플레이어 바꾸기·위에 겹치기: 금지 (III.E.1, III.I.5~7, RMF).

## 화면 구성

| 화면 | 내용 |
|---|---|
| 홈 | 제목 · 흰 '검색' · '구독' / '보관함' · 이어서 보기(최근 기록) · 구독 채널 새 동영상(로그인) · 인기 음악 · 인기 동영상 · 최근 검색 · 계정(로그인/내 계정) |
| 검색 | 말·키보드 입력 → 결과(동영상 카드 · 채널 줄 · 재생목록 줄) · 더 보기 |
| 구독 | (로그인) 구독 채널 새 동영상 · 채널 목록 |
| 보관함 | 기록(이 앱에서 본 영상) · 좋아요 표시한 동영상(로그인) · 내 재생목록(로그인) · 계정 |
| 채널 | 동그란 사진 · 이름 · 구독자 · 동영상(최신순) · 재생목록 |
| 재생목록 | 제목 · 개수 · 채널 · '모두 재생' · 동영상 |
| 동영상 메뉴(길게) | 큰 그림 · 재생 · 채널로 가기 · 폰 유튜브에서 보기 · 기록에서 삭제 |
| 로그인 | 큰 코드 · '폰에서 google.com/device 열기' · 기다리는 중 / 끝남 / 거절 |
| 계정 | 내 채널 이름·사진 · 로그아웃(토큰 철회 + 받은 데이터 삭제) |
| 재생 | 앱 안 GeckoView 로 재생 화면(web/tube) — 공식 플레이어 200×200 + 아래 조작·다음 동영상. 목록(재생목록·검색 결과·피드)을 그대로 이어 재생 |

'듣는 곳' 고르기·프리미엄 안내 화면은 없앤다.

## 모양 (유튜브 다크 + 둥근 화면)

- 바탕 #000, 글자 #F1F1F1, 둘째 줄 #AAAAAA, 표면 #212121, 칩 #272727, 진행·LIVE 빨강.
- 동영상 카드 = 유튜브 앱처럼 **16:9 큰 미리보기**(모서리 12dp, 오른쪽 아래 길이 배지) + 굵은 제목 두 줄 + '채널 · 조회수 · 언제'.
- 채널 줄 = 동그란 사진 + 이름 + 구독자. 재생목록 줄 = 미리보기 + '▶ 개수' + 제목.
- 유튜브 로고·빨간 로고 모양은 쓰지 않는다 (제목은 글자 '유튜브').
- 지난번의 넓은 줄 + 가장자리 줄 작게(EdgeScale), 흰 주 버튼, 큰 글씨를 그대로 쓴다. 불러오는 동안 회색 자리(스켈레톤).

## 데이터 (YouTube Data API v3)

- 공개 데이터는 API 키, 내 데이터는 OAuth 액세스 토큰(youtube.readonly 하나만).
- 인기: `videos.list chart=mostPopular regionCode=KR [videoCategoryId=10]` (1)
- 검색: `search.list type=video,channel,playlist regionCode=KR relevanceLanguage=ko` (100) + `videos.list`(길이·조회수, 1).
  한도가 다 되면 동영상만 카카오 동영상 검색으로 (지금처럼).
- 채널: `channels.list` (1), 업로드 = 업로드 재생목록(UC→UU) `playlistItems.list` (1)
- 재생목록: `playlistItems.list` (1) + `videos.list` (1), 채널의 재생목록 `playlists.list channelId=` (1)
- 내 데이터: `channels.list mine=true`(계정), `subscriptions.list mine=true`, `videos.list myRating=like`, `playlists.list mine=true` (각 1)
- 구독 피드: 구독 채널(관련도순) 최대 15개의 업로드 재생목록 최신 3개씩 → 날짜순 30개 → `videos.list` (약 17).
- 응답은 메모리에만 잠깐(15~30분) — 받은 데이터를 파일로 남기지 않는다(정책 III.E.4). 기록(이 앱에서 본 영상)은 지금처럼 30일.
- 하루 한도 10,000: 홈 새로 고침 2~20, 검색 101.

## 로그인 (OAuth 2.0 기기 흐름)

- 구글 클라우드: 클라이언트 종류 'TV 및 입력 제한 기기', 범위 `youtube.readonly`.
  동의 화면은 '프로덕션'(검증 안 됨 경고는 '고급 → 계속', 토큰 7일 만료 없음).
- 앱: `device/code` → 코드 표시 → `token` 을 interval 마다(slow_down 이면 +5초) 물음, expires_in 이 지나면 끝.
  비밀번호는 워치에 넣지 않는다 — 폰(또는 PC)에서 google.com/device 에 코드를 넣고 승인.
- 토큰: 안드로이드 키 저장소(AES-GCM)로 암호화해 앱 안에만. 만료 전 refresh, refresh 가 거절되면(철회) 로그아웃 처리.
- 로그아웃: `revoke` + 토큰·받은 데이터 지우기 (정책 III.D.2.3).
- 개인정보 처리방침 페이지(web/privacy.html)에 무엇을 쓰는지·철회 방법(구글 보안 설정) 안내 (정책 III.A.2).
- 빌드: `YOUTUBE_OAUTH_CLIENT_ID`·`YOUTUBE_OAUTH_CLIENT_SECRET` (GitHub Secrets / local.properties). 없으면 로그인 버튼 대신 '로그인 준비 중'.

## 앱 안 재생 (GeckoView)

- 워치엔 시스템 WebView 가 없다 → GeckoView 158(armeabi-v7a·arm64-v8a, x86 제외). APK 약 110MB.
  Kotlin 2.4.20·compileSdk 37 이 필요해 올렸다(기존 시험 291개 통과 확인).
- `TubePlayerActivity` 는 **따로 된 프로세스(:player)** — 엔진이 죽어도 앱 본체는 살아 있다.
- 불러오는 주소: GitHub Pages 의 재생 화면 `…/tube/#v=…` (Referer 가 정해진 https 주소여야 함, RMF).
  재생 화면에 목록 넘기기 추가: `ids=a,b,c`(최대 50) · `i=시작 번호` · `list=재생목록ID` · `mix=1`(지금처럼) · `app=1`(앱 안).
- 세션 설정: `suspendMediaWhenInactive(true)`, 추적 보호 끔(광고·플레이어 부품을 막지 않게 — III.I.5).
- 권한: 자동 재생(소리 포함)만 허용 → '▶ 를 눌러 주세요'가 없다. 나머지 권한은 거부.
- 이동: 재생 화면·유튜브 플레이어 안 이동만 허용. `kakaowatch://tube` → 앱 목록으로, `kakaowatch://tube/phone?…` → 폰에서 이어 보기(지금처럼 한 번 묻기),
  그 밖의 https(유튜브 로고 등) → 폰에서 열기. 새 창은 열지 않는다.
- 화면: onStart 에 setActive(true), onStop·앰비언트(손목 내림)에 setActive(false) → 재생 화면이 '숨김'을 보고 멈춘다(지금 규칙 그대로).
  재생 중엔 화면 켜 두기(MediaSession onPlay/onPause).
- 베젤·크라운 → 재생 화면 스크롤. 옆으로 쓸기 → 목록으로.
- 실패하면: 엔진을 못 띄우거나(라이브러리·메모리) 재생 화면을 못 불러오면 → 알리고 삼성 인터넷 재생 화면으로.
  시작 표시 파일을 남겨 두고 첫 화면이 그려지면 지운다 — 남아 있으면(지난번에 죽음) 하루 동안 삼성 인터넷으로 열고 알린다.

## 시험

- 단위(Robolectric): 새 API 응답 파싱(실제 모양의 예시 JSON), 홈 구역 만들기, 화면 이동(뒤로 쌓기), 로그인 흐름(가짜 구글 서버:
  코드·기다림·slow_down·거절·만료·성공·refresh·철회), 토큰 암호화 저장, 재생 시작 판단(앱 안 / 삼성 인터넷 / 지난번 죽음), 재생 주소 만들기,
  재생 화면 이동 판단(허용·앱으로·폰으로·막기).
- 화면 그림(-Prender): 모든 새 화면, 보통·큰 글자.
- 무작위 사용자 여정: 새 화면들 사이를 아무렇게나 — 갇히지 않음·뒤로가 늘 한 칸·로그인 안 했으면 내 데이터 화면이 로그인으로·재생은 고른 목록 그대로.
- 재생 화면 시뮬레이터: 목록 넘기기(ids·list) 시나리오 추가, 7가지 화면 크기, 무작위 사용자, 실제 유튜브 플레이어 시험.
- GeckoView 는 이 컴퓨터에서 돌릴 수 없다(에뮬레이터 없음) → 엔진에 닿는 부분은 얇게, 판단은 따로 시험. 워치에서 처음 쓸 때 실패하면 자동 전환.
