# 유튜브 앱처럼 — 탭·카테고리·알고리즘 홈·Shorts — 설계

날짜: 2026-10-15 · 대상: 갤럭시워치9 44mm (Wear OS 6, 480×480 원형, 32비트 armeabi-v7a) · 앞 설계: `2026-10-14-watch-youtube-app-design.md`

## 사용자 요청

> 유튜브앱 저거 속에있는거 까지 완전 똑같이 진짜 유튜브앱처럼 바꿔줘. 카테고리 있는거처럼 전체에는 알고리즘으로 해서 구독 안한것도
> 뜨게되고 음악 게임 이런 카테고리가있고, 쇼츠보는곳과 영상 보는곳을 따로따로 해줘.

설계 질문에 대한 답 (2026-10-15): **"시간이 아무리 오래 걸려도 되니깐 알고리즘 기능 가져와."**

## 할 수 있는 것과 없는 것 (공식 규칙)

| 바라는 것 | 공식으로 되는가 | 이 앱이 하는 것 |
|---|---|---|
| 내 계정의 진짜 유튜브 홈 추천 | **안 됨** — Data API 에 홈 피드가 없고, 앱 내부 API(InnerTube)는 약관 위반·계정 위험 | 아래 '알고리즘' — 유튜브 자신의 추천(믹스)을 공식 플레이어 함수로 받아 섞는다 |
| 구독 안 한 채널의 동영상 | 됨 | 믹스 추천·인기 차트·내가 본 채널의 새 동영상 |
| 음악·게임 카테고리 | 됨 | `videos.list chart=mostPopular videoCategoryId=10/20` (2025-07-21 부터 인기 음악·영화·게임 차트) + 동영상의 `categoryId` |
| 실시간·뉴스 | 됨 | 실시간 = `search.list eventType=live` (검색 한도 — 그 칩을 열 때만, 3시간 기억) · 뉴스 = 인기 차트 `videoCategoryId=25` |
| Shorts 따로 보기 | 됨 (공식 'Shorts' 표시는 없음) | 세로(높이 ≥ 너비)·3분 이하 = Shorts. 채널의 Shorts 목록(`UUSH…`) + 세로 동영상 판별(`player.embedHeight/embedWidth`) |
| 화면 꺼져도 재생·광고 없이 | **안 됨** (III.I.9, 공식 플레이어는 로그인 안 됨) | 지금처럼 '폰에서 이어 보기' |

지켜야 하는 규칙 (확인한 원문, 2026-10-15):
- 플레이어 최소 200×200, 플레이어 앞에 아무것도 겹치지 않기, 자동 재생은 플레이어가 절반 넘게 보일 때만, 재생을 시작하는 미리보기는
  120×70 이상, 한 화면에 저절로 재생되는 플레이어는 하나만 (Required Minimum Functionality).
- API 데이터 보관은 30일 이하 (III.E.4.c·d), 받은 데이터로 새 지표·점수를 만들지 않기 (III.E.4.h), 플레이어를 바꾸거나 막지 않기 (III.I.6),
  보이지 않는 재생 금지 (III.I.9), 데이터를 새로 쓰기 시작하면 개인정보 처리방침에 다시 동의 받기 (III.E.3).
- III.I.1 — 유튜브의 핵심 경험을 그대로 흉내 내려면 '상당한 독자적 가치'가 있어야 한다. 이 앱의 독자적 가치: 유튜브에는 갤럭시워치 앱이 없다.
  둥근 화면·베젤 조작·폰으로 이어 보기·워치 타일·카카오 검색 대체·길 안내 중 사용. 유튜브 로고·Shorts 로고·빨간 모양은 쓰지 않는다
  (글자 '유튜브'·'Shorts'만, 아이콘은 우리 것).

## 알고리즘 ('전체')

유튜브의 추천을 공식으로 얻는 길은 **유튜브 믹스**뿐이다. 믹스(`list=RD<동영상>`)는 유튜브가 그 동영상과 비슷한 것을 골라 만든 목록이고,
IFrame 플레이어의 문서화된 함수 `player.getPlaylist()` 가 그 목록의 동영상 번호를 돌려준다.

1. **누르면 믹스로 이어서** — 홈·검색·구독·채널·기록에서 동영상을 누르면 그 동영상을 틀고, 다음 동영상은 유튜브 믹스가 정한다
   (유튜브 앱의 '자동재생 다음 동영상'처럼). 재생목록·좋아요·내 재생목록은 지금처럼 목록 순서대로.
2. **믹스 받아 두기** — 앱 안 재생 화면(app=1)이 믹스 목록을 받으면 `kakaowatch://tube/recs?seed=<처음>&ids=<나머지 ≤49>` 로 앱에 알린다.
   앱은 받은 번호만 워치에 **7일까지**(최근 믹스 12개까지) 둔다. 인터넷 앱(삼성 인터넷)으로 틀 때는 알리지 않는다.
3. **'전체' 만들기** — 네 가지를 번갈아 섞는다 (점수 없이, 출처 차례로):
   - R 믹스 추천: 받아 둔 번호(새 믹스부터 번갈아 ≤100개) → `videos.list`(최신 제목·그림·길이)
   - S 구독 새 동영상(로그인): 지금의 구독 피드
   - W 내가 본 채널(구독 안 한): 이 앱 기록의 최근 채널 4개 × 긴 동영상 최신 3개 (`UULF…`, 없으면 `UU…`)
   - T 인기(한국): `chart=mostPopular`
   - 차례: `R S R T W R S T` 를 되풀이, 다 쓴 출처는 건너뜀. 처음 쓰는 사람(믹스·기록 없음, 로그아웃)은 인기만.
   - 빼는 것: 이 앱에서 이미 본 동영상, '관심 없음', '채널 추천 안 함' 채널, 시작 전 생방송, Shorts(→ 선반으로).
   - 한 채널이 10개 연속 안에 2개를 넘지 않게 뒤로 미룬다. 넷째 카드 자리에 **Shorts 선반**(가로로 넘기는 세로 카드, 최대 10개).
   - 끝의 '더 보기' = 인기 다음 쪽을 붙여 다시 섞는다.
4. **'관심 없음' · '채널 추천 안 함'** — 동영상을 길게 눌러. 워치에 30일, 홈의 모든 칩에서 뺀다 (구독·채널 화면엔 그대로).

## 화면

### 공통: 맨 위 탭

`[홈] [Shorts] [구독] [나]` — 네 화면(홈·Shorts·구독·나)의 제목 아래 한 줄 (아이콘 + 작은 글자, 고른 탭은 흰색).
홈 탭 = 홈으로(이미 홈이면 맨 위로). 다른 탭 = 홈 위에 그 화면 하나 (탭끼리 바꾸면 자리만 바뀌어 뒤로 = 홈).

### 홈

`유튜브` 제목 → 탭 → 흰 `검색` → **칩 줄**(가로로 넘김, 고른 칩 흰색) → 칩의 내용.

| 칩 | 내용 |
|---|---|
| 전체 | 위의 알고리즘 + Shorts 선반 + 더 보기 |
| 믹스 | 믹스 카드: 최근 본 동영상(음악 먼저) 8개를 씨앗으로 `믹스 – 제목` (누르면 그 믹스). 기록이 적으면 인기 음악으로 채움 |
| 음악 | 받아 둔 것 중 `categoryId=10` + 인기 음악 차트 (번갈아) |
| 게임 | `categoryId=20` + 인기 게임 차트 |
| 실시간 | 받아 둔 것 중 생방송 + `search eventType=live` (칩을 열 때만, 3시간) |
| 뉴스 | `categoryId=25` + 인기 차트 `videoCategoryId=25` 중 분류 25 만 (2026-10-14 실측: 10개 중 7개가 뉴스 — 검색 없이 1단위) |
| 최근 업로드 | 받아 둔 전부 중 7일 안에 올라온 것, 새것부터 |
| 감상한 동영상 | 이 앱에서 본 것 (최근 30일) |
| 새로운 맞춤 동영상 | 믹스·인기 중 본 적 없고 구독도 안 한 채널의 것 |

칩은 그 자리에서 바뀐다(뒤로 가기에 쌓이지 않음). '전체'가 아닌 칩에서 뒤로 = '전체'로, 또 뒤로 = 닫기.
예전 홈의 이어서 보기·인기 음악/인기 동영상 구역·최근 검색·계정 줄은 칩·검색·나 탭으로 옮긴다.

### 검색

흰 `검색` → 검색 화면(최근 검색어 목록 + '검색 기록 지우기')이 열리면서 곧바로 음성·키보드 입력. 입력하면 결과로 바뀐다(뒤로 = 앞 화면).
결과: 채널 → 동영상(사이사이 재생목록) + 결과 속 Shorts 는 셋째 동영상 뒤 **Shorts 선반**. 동영상을 누르면 믹스로 이어서.

### Shorts 탭

`Shorts` 제목 → 탭 → 흰 `▶ Shorts 보기` → 세로 카드 2칸 격자. 탭으로 들어오면 준비되는 대로 **Shorts 재생 화면을 바로 연다**
(보고 있을 때만 — 손목을 내렸으면 다시 볼 때, 떠났으면 안 엶). 재생 화면에서 뒤로 오면 이 격자.

Shorts 고르기 (Feed `shorts`, 30분 기억): 구독 채널 앞 8개 + 최근 본 채널 4개의 `UUSH…` 최신 4개씩 + 믹스 추천 중 Shorts →
`videos.list` → 세로·3분 이하만, 채널이 이어지지 않게 번갈아, 이미 본 Shorts 는 뒤로(6개보다 적으면 다시 씀).
10개보다 적으면 `search type=video videoDuration=short q=#shorts regionCode=KR` (3시간 기억)으로 채운다.

### 구독

`구독` 제목 → 탭 → **채널 사진 줄**(가로로 넘김, 누르면 채널, 끝에 '전체' → 채널 목록) → 칩 `[전체] [동영상] [Shorts] [실시간]`.
전체 = 구독 피드의 긴 동영상 + 넷째 자리 Shorts 선반, 동영상 = 긴 동영상, Shorts = 구독 채널 `UUSH…` 격자, 실시간 = 생방송·지난 방송.
로그인 안 했으면 지금처럼 로그인 안내.

### 나

내 채널(사진·이름) 또는 '로그인' → 탭 → `기록`(최근 2개 + '기록 모두 보기') → 내 재생목록·좋아요(로그인) →
'추천에 쓰는 정보' 안내(믹스 추천 N개·관심 없음 M개 · 7일/30일 뒤 저절로 지워져요) → `기록 지우기`(본 동영상·검색어·믹스 추천·관심 없음·본 Shorts 모두) →
`약관 및 개인정보` → (로그인) 내 계정(로그아웃·권한).

### 채널

사진·이름·구독자 → 칩 `[동영상] [Shorts] [실시간] [재생목록]` (`UULF…` · `UUSH…` 격자 · `UULV…` · 재생목록). `UULF` 가 없으면(404) `UU…`, `UULV` 가 없으면 빈 목록 (비어 있으면 그대로 — 긴 동영상이 없는 채널에 Shorts 가 섞이지 않게).

### 동영상 메뉴 (길게)

큰 그림 · 재생 · 채널로 가기 · 폰 유튜브에서 보기 · **관심 없음** · **채널 추천 안 함** · (기록이면) 기록에서 삭제 · 취소.

### 동영상 재생 화면 (web/tube/index.html) 바뀌는 것

- 믹스 목록을 받으면(앱 안에서만) 위의 recs 링크를 한 번 (씨앗마다, 믹스가 끝나 이어 받으면 그 믹스도).
- 제목 아래 채널 이름을 누르면(앱 안·인터넷 앱 모두) `kakaowatch://tube/channel?v=<지금 동영상>` → 앱이 채널을 찾아(1단위) 채널 화면.
- 그 밖(재생 규칙·조작·다음 동영상)은 그대로.

### Shorts 재생 화면 (새 web/tube/shorts.html)

- 주소: `…/tube/shorts.html#ids=<≤50개>&i=<시작>&n=<고른 시각>&app=1`. 앱 안(GeckoView)·인터넷 앱 둘 다.
- **화면 폭 284** (동영상 화면은 240): 플레이어 200×200 이 가운데(대각선 283 까지 둥근 화면 안), 위아래 42px 띠가 남는다 —
  위 띠 = 제목(두 줄, 둥근 화면에 맞춰 작게), 아래 띠 = 채널 알약(누르면 앱의 채널 화면). 플레이어 앞에는 아무것도 없다.
  세로 동영상은 200×200 상자 안 112×200 으로 둥근 화면 안에 다 들어간다.
- 한 Shorts = 화면 한 장. 위아래로 넘기면(손가락·베젤) **한 장씩** 다음/앞 Shorts. 스크립트가 맞춘다: 멈춘 자리가 지금 장에서
  8px 넘게 움직였으면 그 방향으로 한 장, 아니면 제자리 (세게 튕겨도 한 장). 앱 안에서는 베젤 한 칸 = 한 장 (TubePlayerActivity 가 화면 높이만큼 굴림).
- 플레이어는 지금 장에만 하나(다른 장은 미리보기 그림 120×200 — 누르면 그 장으로). 장이 바뀌면 앞 플레이어를 없애고 새로 만든다.
- 보이면 바로 재생(방금 고른 것·넘긴 것), 끝나면 처음부터 다시(Shorts 처럼 반복). 2분 동안 만지지 않으면 반복을 멈춘다(배터리 · 안 보는 사이 저절로 거듭 틀지 않게).
  화면이 꺼지거나 가려지면 멈춤, 다시 보여도 저절로 틀지 않음(▶). 막히면 '▶ 를 눌러요', 못 트는 Shorts 는 알리고 2.5초 뒤 다음 장.
- 처음 재생될 때 앱에 `kakaowatch://tube/seen?v=<번호>` (앱 안에서만) — 앱은 본 Shorts 를 30일 기억해 다음엔 뒤로 미룬다.
- 마지막 다음 장: 'Shorts를 다 봤어요' + `처음부터` + `목록으로`(앱) / `다른 동영상 찾기`(인터넷 앱).
- 제목·채널 이름은 oEmbed (동영상 화면과 같음). 화면 켜 두기는 재생 중에만.

## 데이터 사용량 (하루 1만 단위 · 검색 하루 100번)

- 홈 '전체' 새로 받기 ≈ 인기 1 + 믹스 정보 ≤2 + 구독 피드 ≈17 + 본 채널 ≤5 + Shorts ≈14 = **약 40단위**, 메모리에 15~30분.
- 음악·게임·뉴스 칩 +1씩, 실시간 칩 = 검색 1번(3시간 기억), Shorts 검색 보충 = Shorts 탭에서만 1번(3시간, 저절로는 하루 4번까지 — 워치에 셈). 동영상 화면 채널 링크 = 1.
- 받은 데이터는 메모리에만. 워치에 남는 것: 기록 30일(지금), 믹스 추천 번호 7일, 관심 없음·본 Shorts 30일 — 모두 '기록 지우기'로 지워짐.

처리방침에 추가: 이 앱에서 본 기록·믹스 추천 번호·관심 없음·본 Shorts 를 **워치 안에서만** 추천에 쓴다(서버 없음, 보내지 않음),
보관 기간, 지우는 법. `TERMS_VERSION` 1→2 로 다음에 열 때 다시 동의를 받는다 (III.E.3). 약관 화면 글도 같은 내용.

## 시험

- 단위: 파서(categoryId·portrait), 링크(UU*·shorts·recs/seen/channel 읽기 — 이상한 값), 추천 보관(7일·12개·30일·지우기), inbox(원자적·최대·읽고 지움),
  TubeHome(칩마다 · 중복 · 본 것 · 관심 없음 · 채널 몰림 · Shorts 빼기 · 처음 사용자), TubeNav(새 화면 저장/복원·swapTop), PlayerNav(shorts·recs·seen·channel).
- YouTubeData(가짜 HTTP): maxHeight·fields, UULF/UULV 404 → UU, searchVideos 조건, Shorts 거르기.
- 앱(Robolectric): 탭·칩·뒤로, Shorts 탭 바로 열기(보고 있을 때만), 관심 없음, inbox 의 믹스 → 전체에, 큐 = 믹스(재생목록은 순서), 채널 탭, 검색 화면, 다시 동의, 채널 링크.
- 화면 그림(480 원형): 홈(탭·칩·선반)·Shorts 격자·구독(사진 줄)·나·채널 탭·메뉴.
- 시뮬레이터: 동영상 화면 recs(앱 안에서만·씨앗마다 한 번·49개 이하)·채널 링크 / Shorts 화면 전부(보일 때만 재생·한 장씩·튕겨도 한 장·반복·5분·숨김·막힘·못 트는 것·끝 장·채널·seen·인터넷 앱·겹침·200×200·미리보기 크기·둥근 화면).
- 실제 API 확인(GitHub Actions 'YouTube API check'): UUSH/UULF/UULV, embedWidth/Height, categoryId, 인기 10/20.

## 위험과 대비

- **재생 화면 → 앱 링크가 사용자 조작 없이도 전달되는지** (GeckoView 는 모든 이동을 onLoadRequest 로 넘긴다 — 확인한 소스 기준).
  안 되면 믹스 추천만 빠지고 나머지는 그대로 된다. '나' 탭의 '믹스 추천 N개'로 실제 워치에서 확인할 수 있다.
- `UUSH/UULF/UULV` 는 문서에 없는 자동 재생목록 — 404·빔이면 UU + 세로·길이 판별로 대신, 검색 보충.
- 베젤 한 칸의 굴림 양은 기기마다 다름 → Shorts 는 한 칸 = 화면 한 장으로 앱이 굴리고, 페이지가 한 장씩 맞춘다.
- 메모리(2GB): 플레이어는 늘 하나, 미리보기는 지금 장 앞뒤만 불러온다.

## 검토 뒤 바뀐 것 (2026-10-15, 코드·정책 검토)

- **어린이용(Made for Kids, 정책 III.E.4.j)**: 동영상 정보에 `status.madeForKids`. 모르면(예전 기록·정보를 다 못 받은 검색 결과)
  앱에 넣어 틀기 전에 찾아보고(1단위), 못 찾으면 폰 유튜브로. 어린이용이면 시청 기록·믹스 추천·본 Shorts 에 남기지 않는다 —
  재생 화면에 `k=1`(동영상)·`k=번호들`(Shorts)을 붙여 알리지 않게. 이어 받은 믹스(씨앗 = 마지막 곡)는 어린이용인지 몰라 알리지 않는다.
- **보관 기간**: 받은 편지는 보낸 때를 함께 주고, 보관은 보낸 때부터 (믹스 추천 7일 · 본 Shorts 30일). 7일 지난 글은 버린다.
  시청 기록은 정보를 받은 때를 따로 두고 7일마다 새로 받는다 (없어진·어린이용은 지움, 받은 지 30일 넘는 정보는 두지 않음).
- **Shorts 탭 바로 열기**: 다 받았거나 10개 모였을 때 (일부만 받은 목록으로 열지 않게), 저절로 열 땐 폰을 열지 않는다.
- **한도·들썩임**: '본 채널'·Shorts 후보의 열쇠는 채널 묶음(차례 무관), 로그인했으면 구독 채널을 받은 뒤에 '본 채널',
  열쇠가 바뀌면 새것을 받는 동안 바로 앞 것을 보여 준다.
- **재생 화면 링크**: 워치 앱 링크·알림은 재생 화면이 보낸 것만 (엔진이 알려 준 보낸 곳이 다른 곳이면 막음).
- **그 밖**: 구독의 Shorts·실시간 칩은 구독 채널이 없거나 못 받으면 비었다는 말·다시 시도, '기록 지우기'는 본 Shorts·검색어만 있어도,
  지워도 유튜브 계정 쪽은 그대로라고 알림, Shorts 아이콘은 재생 삼각형 없는 우리 그림, Shorts 는 믹스 씨앗에서 뺌.
- **남은 정책 위험 (사용자에게 알림)**: 유튜브 앱을 닮은 화면·'Shorts' 이름, 믹스(`list=RD…`)의 다음 동영상을 홈 추천에 쓰는 것,
  문서에 없는 `UUSH/UULF/UULV`, 모양(세로·3분 이하)으로 Shorts 를 가리는 것은 정책 해석에 따라 문제가 될 수 있다 (개인용 앱).
