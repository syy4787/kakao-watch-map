# 워치 유튜브 재생 화면 시뮬레이터

`web/tube/index.html`(워치 삼성 인터넷으로 여는 재생 화면)을 실제 크로미움에 띄우고, **가짜 유튜브 플레이어**(`fake_yt.js`)로
사용자가 겪을 수 있는 경우를 돌린 뒤 매 순간 규칙을 확인한다. `web/` 이 바뀌어 GitHub Pages 로 올릴 때 Actions 가 먼저 이것을 돌리고,
하나라도 실패하면 올리지 않는다 (실패한 순간의 화면은 Actions 의 Artifacts 에).

- 가짜 플레이어는 실제 IFrame 플레이어에서 잰 동작을 흉내 낸다
  - 알림은 실제처럼 비동기(postMessage), 페이지가 읽는 값(상태·번호·목록)도 알림이 갈 때 바뀜
  - 소리 자동 재생이 막히면 -1 + `onAutoplayBlocked`, 사용자가 누르면 재생
  - 재생목록 중간 곡이 끝나면 '끝남' 없이 바로 다음 번호, 마지막 곡에서 nextVideo 는 그 곡을 처음부터
  - 오류 곡은 -1→3→onError→-1, 이미 있는 플레이어에 믹스를 넣으면 고른 곡이 맨 앞이 아님
  - 불러오는 중 멈춤: 보통은 -1 에 머물고, `pauseLate` 면 멈춤을 놓치고 계속 불러와 재생까지 감
  - `freeze()/thaw()`: 화면이 꺼져 브라우저가 멈춘 동안 플레이어도 멈췄다가 깨어남 (페이지 시계는 `page.clock.fastForward` 로 건너뜀)
- 확인하는 것
  - 유튜브 규칙: 플레이어 200×200·위에 아무것도 안 겹침·**재생 시작은 플레이어가 보일 때만**(점을 찍어 실제로 보이는지 잼)·숨기면 멈춤·
    재생을 시작하는 미리보기 120×70 이상
  - 단단함: 가로로 안 넘침·보이는 요소가 둥근 화면 밖으로 안 나감·화면 켜 두기는 재생 중(과 다음 곡으로 넘어가는 잠깐)만·▶ 표시가 실제 상태와 같음·
    ⏸ 뒤에 다시 재생되거나 화면이 켜져 있지 않음·'넘어가요' 같은 안내가 지켜짐·이상한 글자·페이지 오류 없음
- 정해 둔 시나리오(자동 재생 막힘, 막힌 곡, 전부 막힘, 믹스 끝 이어 듣기, 한 곡 반복, 인터넷 끊김, 화면 꺼짐, 화면이 꺼진 사이 고른 곡,
  뒤로 가기, 오래된 탭, 새로 고침, 얼었다 깨어남, 플레이어 준비 안 됨, 연타, 폰에서 이어 듣기, 소리, 잠자기 타이머 …)와 무작위 사용자(씨앗 고정).
  각 보호 장치를 일부러 끄면 해당 시나리오가 실패하는 것까지 확인했다.

```bash
cd tools/tube-sim && npm i --no-save playwright@1.56.0 && npx playwright install chromium
node sim.mjs                 # 정해 둔 시나리오 (226 화면)
node sim.mjs --allvp=1       # 화면 크기 7가지 (226·240·216·200·막대 있는 226×196·360·글자 1.3배)
node sim.mjs --random=100 --steps=30 --seed=1   # 무작위 사용자 100명
node sim.mjs --only=믹스끝   # 이름으로 골라서
node sim.mjs --retry=1       # 실패한 시나리오만 한 번 더 (바쁜 서버에서)
```

실패하면 `--shots` 폴더(기본 `shots/`)에 그 순간의 화면과 `report.json`(가짜 플레이어 기록 포함)이 남는다.
