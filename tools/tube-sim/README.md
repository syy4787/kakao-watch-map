# 워치 유튜브 재생 화면 시뮬레이터 (동영상·Shorts)

`web/tube/index.html`(동영상 재생 화면)과 `web/tube/shorts.html`(Shorts 재생 화면)을 실제 크로미움에 띄우고, **가짜 유튜브 플레이어**
(`fake_yt.js`)로 사용자가 겪을 수 있는 경우를 돌린 뒤 매 순간 규칙을 확인한다. `web/` 이 바뀌어 GitHub Pages 로 올릴 때 Actions 가
먼저 둘 다 돌리고, 하나라도 실패하면 올리지 않는다 (실패한 순간의 화면은 Actions 의 Artifacts 에).

- 가짜 플레이어는 실제 IFrame 플레이어에서 잰 동작을 흉내 낸다
  - 알림은 실제처럼 비동기(postMessage), 페이지가 읽는 값(상태·번호·목록)도 알림이 갈 때 바뀜
  - 소리 자동 재생이 막히면 -1 + `onAutoplayBlocked`, 사용자가 누르면 재생
  - 재생목록 중간 곡이 끝나면 '끝남' 없이 바로 다음 번호, 마지막 곡에서 nextVideo 는 그 곡을 처음부터
  - 오류 곡은 -1→3→onError→-1, 이미 있는 플레이어에 믹스를 넣으면 고른 곡이 맨 앞이 아님
  - 불러오는 중 멈춤: 보통은 -1 에 머물고, `pauseLate` 면 멈춤을 놓치고 계속 불러와 재생까지 감
  - `freeze()/thaw()`: 화면이 꺼져 브라우저가 멈춘 동안 플레이어도 멈췄다가 깨어남 (페이지 시계는 `page.clock.fastForward` 로 건너뜀)
- 확인하는 것 (두 화면 공통)
  - 유튜브 규칙: 플레이어 칸 200×200 이상(영상 모양대로 — 둥근 화면 안에 통째로·크게, 플레이어가 아는 크기 = 보이는 칸)·위에 아무것도 안 겹침·**재생 시작은 플레이어가 보일 때만**(점을 찍어 실제로 보이는지 잼)·숨기면 멈춤·
    재생을 시작하는 미리보기 120×70 이상·플레이어는 하나
  - 단단함: 가로로 안 넘침·보이는 글자·단추가 둥근 화면 밖으로 안 나감·화면 켜 두기는 재생 중(동영상 화면은 다음 곡으로 넘어가는 잠깐도)만·
    '넘어가요' 같은 안내가 지켜짐·이상한 글자·페이지 오류 없음
  - 앱으로 가는 링크: 앱 안(`app=1`)은 `kakaowatch://`, 인터넷 앱은 `intent://` · 믹스 알림(`tube/recs`)은 앱 안에서 연 믹스에서만·
    씨앗마다 한 번·49개까지 · 본 Shorts 알림(`tube/seen`)은 앱 안에서만·재생된 것만·한 번씩
- 동영상 화면(`sim.mjs`) 시나리오: 자동 재생 막힘, 막힌 곡, 전부 막힘, 믹스 끝 이어 듣기, 한 곡 반복, 인터넷 끊김, 화면 꺼짐,
  화면이 꺼진 사이 고른 곡, 뒤로 가기, 오래된 탭, 새로 고침, 얼었다 깨어남, 플레이어 준비 안 됨, 연타, 폰에서 이어 듣기, 소리, 잠자기 타이머,
  믹스 알림(앱 안·인터넷 앱·목록), 채널 링크 …와 무작위 사용자(씨앗 고정)
- Shorts 화면(`shorts_sim.mjs`) 시나리오: 바로 재생·오래된 주소, 베젤 한 칸 = 한 장(빠르게 여러 칸도), 손가락은 세게 튕겨도 한 장
  (플레이어 위에서 밀어 페이지가 손가락을 못 보는 경우도 — CDP 로 진짜 손가락 끌기), 8px 이하는 제자리, 키, 화면 꺼짐·돌아와도 안 틂,
  멈춤을 놓친 늦은 시작, 자동 재생 막힘 → 플레이어 ▶, 못 트는 Shorts → 알리고 다음 장(숨김이면 안 넘어감), 반복·오래 안 만지면 반복 멈춤,
  끝 장, 채널 단추(칸 오른쪽)·안내 글(칸 왼쪽), 볼 것 없음·이상한 목록·스크립트 실패, 주소 바뀜·뒤로, 미리보기 누르기, 긴 제목, 크기 바뀜 …와 무작위 사용자.
  매 단계: 멈추면 늘 장에 맞춰지는지, 플레이어는 지금 장에만 하나인지도 본다. 화면 284(기본)·240·300·226 · 낮은/높은 화면 280×240·226×196·226×300 (페이지 폭은 늘 480 — 정사각 화면은 모두 같은 배치)
- 각 보호 장치를 일부러 끄면 해당 시나리오가 실패하는 것까지 확인했다.

```bash
cd tools/tube-sim && npm i --no-save playwright@1.56.0 && npx playwright install chromium
node sim.mjs                 # 동영상 화면: 정해 둔 시나리오 (226 화면)
node sim.mjs --allvp=1       # 화면 크기 7가지 (226·240·216·200·막대 있는 226×196·360·글자 1.3배)
node sim.mjs --vp=226x196,226_text1.3   # 고른 화면 크기만 (정사각 화면은 페이지 폭 480 으로 같은 배치라 다른 것만 골라도 됨)
node sim.mjs --random=100 --steps=30 --seed=1   # 무작위 사용자 100명
node shorts_sim.mjs          # Shorts 화면: 정해 둔 시나리오 (284, 표시한 것은 나머지 6가지 화면에서도)
node shorts_sim.mjs --allvp=1                   # 모든 시나리오를 화면 7가지로
node shorts_sim.mjs --random=30 --steps=30 --seed=1   # 무작위 사용자 30명
node sim.mjs --only=믹스끝   # 이름으로 골라서 (shorts_sim.mjs 도 같음, --vp=280 은 그 화면만)
node sim.mjs --retry=1       # 실패한 시나리오만 한 번 더 (바쁜 서버에서)
```

실패하면 `--shots` 폴더(기본 `shots/`)에 그 순간의 화면과 `report.json`·`shorts_report.json`(가짜 플레이어 기록 포함)이 남는다.
